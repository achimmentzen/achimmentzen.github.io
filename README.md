# Achim Mentzen — Living Sculpture / Transparenzprojekt

**Achim Mentzen · Living Sculpture / Transparenzprojekt · 2026**

This is the public website repository for the **Living Sculpture / Transparenzprojekt**.

The project is a public art and self-documentation project addressing body autonomy, nudity, shame conditioning, radical transparency, self-determination and delegated decision-making.
