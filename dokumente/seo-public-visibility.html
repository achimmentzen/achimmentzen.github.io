Technical discovery

  • Every important HTML page should have a distinct, descriptive title element.
  • Every important HTML page should have a relevant meta description.
  • Use crawlable anchor elements with href attributes and descriptive anchor text.
  • Keep robots.txt permissive for public project material.
  • Keep sitemap.xml current with canonical public URLs.
  • Use structured data only for facts that are actually present on the page.
  • Keep the artist name and project name consistent across page titles, descriptions, press material and public listings.
  • Do not use keyword stuffing, fabricated claims, impersonation, hidden text or attempts to bypass platform rules.

Resilience

The project should maintain multiple independent public copies and an auditable Git history. No web publication can honestly be guaranteed to be undeleteable: a platform owner can remove content or an account can become inaccessible. The practical goal is therefore redundancy, version history, independent copies and rapid restoration.
